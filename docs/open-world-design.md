# 开放世界设计规范

- 适用版本：垂直切片至正式版
- 核心原则：可见即可探索、路径上持续有发现、人工设计关键体验、程序化生产自然背景

## 1. 世界规模

完整世界不一次性制作。采用多个大型区域逐步扩展：

| 层级 | 建议规模 | 用途 |
|---|---:|---|
| 垂直切片 | 1 km × 1 km | 验证探索、战斗、任务和流式加载 |
| 单个正式区域 | 2～4 km² | 一个生态主题与主线章节 |
| 完整世界 | 4～6 个区域 | 长期目标，按生产能力调整 |

规模是内容预算，不是宣传指标。若单位面积缺少有效事件，应缩小地图而不是填充空白。

## 2. 区域结构

每个区域必须包含：

- 一个安全据点。
- 一个从远处可见的主地标。
- 两到三个次级地标。
- 一条主线任务链。
- 三到五个世界任务。
- 若干动态事件、资源点和隐藏地点。
- 一个改变探索方式的区域机制。
- 至少两条连接相邻区域的路线。

垂直切片区域使用“营地—溪谷—松木林—守林站—山脊”结构。主线形成闭环，玩家也能偏离路线探索洞穴、猎人营地和观景点。

## 3. 探索密度

参考节奏：

- 每 20～40 秒出现一次视觉、声音或资源反馈。
- 每 1～2 分钟出现一次可交互内容。
- 每 3～5 分钟出现一个小型事件、谜题或战斗。
- 每 8～12 分钟到达一个重要地标。

这些是调试基线，不应机械铺设。安静路段用于建立氛围，但必须有明确构图、声音或远景目标。

## 4. 地标分级

### S 级：区域主地标

山峰、巨树、瞭望塔等，承担方向定位和章节目标。区域多数位置应能看见其轮廓。

### A 级：路线地标

守林站、瀑布、石门、废弃吊桥等，负责连接探索路线和任务。

### B 级：局部记忆点

奇特岩石、倒木、营火、路牌等，帮助玩家确认当前位置。

任何关键任务位置都不能只依赖小地图图标，至少提供一个世界内线索。

## 5. 兴趣点类型

| 类型 | 预期时长 | 奖励 |
|---|---:|---|
| 资源点 | 10～30 秒 | 制作材料 |
| 环境线索 | 30～90 秒 | 叙事、地图信息 |
| 小型谜题 | 1～3 分钟 | 宝箱、捷径 |
| 动态事件 | 2～5 分钟 | 资源、声望 |
| 敌人据点 | 3～6 分钟 | 装备、区域安全度 |
| 隐藏地点 | 3～10 分钟 | 独特物品、世界观 |
| 地下空间 | 5～15 分钟 | 独立探索段落 |

## 6. 移动与边界

完整版本支持行走、冲刺、下蹲、跳跃、攀爬和有限滑行。垂直切片优先完成行走、冲刺、跳跃和低矮攀越。

世界边界优先使用自然阻挡：

- 陡峭岩壁。
- 深水和急流。
- 极端天气区。
- 倒塌道路。
- 剧情尚未解除的生态异常。

避免使用无解释的透明墙。临时边界必须有世界内反馈。

## 7. 地图与导航

- 地图通过探索逐步绘制，不默认显示全部兴趣点。
- 玩家可放置自定义标记。
- 指南针显示方向和已发现的重要地点。
- 任务可给出区域范围，不总是给出精确坐标。
- 开启辅助模式后可显示更明确的路径提示。
- 不用大量 UI 箭头取代环境引导。

## 8. 动态世界

动态事件由区域条件触发：

~~~text
触发条件 = 时间 + 天气 + 区域状态 + 玩家进度 + 冷却时间
~~~

示例：

- 雨后溪流上涨，原路线被封闭。
- 夜间出现发光植物，引导隐藏入口。
- 清理敌人据点后，商人或动物返回。
- 修复瞭望塔后，地图揭示新地点。

事件必须可中断、可恢复，不得把关键主线永久锁死。

## 9. 流式加载规则

- 世界按 Chunk 加载，区域按更高层级管理。
- 任务关键对象不得因卸载丢失状态。
- 远景地标使用 HLOD 或代理模型常驻。
- 动态对象离开活动范围后序列化为轻量状态。
- 音频、天气和光照跨 Chunk 连续过渡。
- 快速移动时先加载落点安全区，再恢复玩家控制。

## 10. 垂直切片验收

- 玩家不看调试地图也能找到守林站。
- 主路线之外至少有两个有价值的发现。
- 从区域任意主要位置能识别至少一个导航地标。
- Chunk 加载不出现明显模型闪现、坠落或任务丢失。
- 主线、动态事件和天气切换可以同时运行。
- 首次玩家能在 20～30 分钟内完成主任务。
