# Forest Adventure 游戏设计文档

- 文档版本：V1.0
- 游戏类型：第一人称开放世界 / 探索 / 冒险 / 动作 / 轻生存
- 目标平台：Windows PC
- 引擎：Godot
- 美术生产：Blender + 程序化生成
- 游戏模式：单人

## 1. 游戏概念

玩家扮演一名进入偏远山林的游侠。一次突发事件切断了返程路线，玩家必须依靠地图、地标和有限物资穿过森林，同时调查废弃营地、异常自然现象和失踪者留下的线索。

游戏强调沉浸式开放世界探索、方向判断和环境叙事，并逐步加入轻量动作战斗、角色成长和区域任务。危险来自敌对生物、迷路、天气、黑暗与复杂地形。

参考《原神》的是“远处地标吸引玩家—途中不断发现事件—到达目标后解锁新能力或区域”的探索节奏，不复制其角色、剧情、美术资产、地图或具体系统表现。

一句话体验：

> 在没有明确导航线的深林中，根据自然线索找到道路，并活着带回森林里的秘密。

## 2. 设计目标

- 让森林本身成为主要角色，而不只是背景。
- 通过地标、声音、光线和植被变化引导玩家。
- 保持探索压力，但避免繁琐的重度生存数值。
- 每次离开安全区域都应有目标、风险和发现。
- 使用程序化工具提高场景生产效率，同时由人工控制关键路径和叙事节奏。

## 3. 核心游戏循环

1. 在营地确认目标并准备物资。
2. 进入森林，根据地图、指南针和环境地标辨认方向。
3. 搜索资源、线索和安全路径。
4. 应对天气、天色、体力或动物威胁。
5. 到达目标地点，完成环境谜题或调查。
6. 返回营地，整理发现并解锁新区域。

短循环约 30～90 秒：观察 → 移动 → 发现 → 交互。

中循环约 5～10 分钟：选择路线 → 承担风险 → 完成一个局部目标。

长循环约 20～40 分钟：完成一次探索任务并推动主线。

## 4. 玩家能力

### 4.1 基础操作

| 动作 | 默认输入 | 说明 |
|---|---|---|
| 移动 | WASD | 第一人称移动 |
| 观察 | 鼠标 | 控制视角 |
| 冲刺 | Shift | 消耗体力 |
| 下蹲 | Ctrl | 通过障碍、降低动静 |
| 跳跃 | Space | 跨越低矮障碍 |
| 交互 | E | 拾取、调查、开启 |
| 手电筒 | F | 消耗电量 |
| 背包 | Tab | 查看物资与线索 |
| 地图 | M | 显示纸质地图 |
| 指南针 | C | 手持指南针 |

### 4.2 探索工具

- 纸质地图：不显示实时 GPS 位置，玩家需要通过地标定位。
- 指南针：提供方向，不提供目标箭头。
- 手电筒：夜间探索工具，电量有限。
- 望远镜：观察远处地标和动物。
- 相机：记录线索和特殊地点。
- 营火工具：在指定地点恢复状态并保存进度。

## 5. 世界结构

世界采用“多个大型无缝区域 + 分层流式加载”的开放结构。关键地标、任务路径和地下空间由人工设计，自然地形与植被由程序化工具生成并由关卡设计师二次调整。

世界按区域逐步开放，每个区域拥有独立生态、天气、敌人、探索机制和主线章节。玩家可攀登或到达大多数可见地标，但陡峭岩壁、极端天气和能力门槛用于控制早期路线。

### 5.1 区域规划

| 区域 | 视觉特征 | 主要玩法 | 危险 |
|---|---|---|---|
| 林间营地 | 木屋、火堆、补给箱 | 教学、准备、任务选择 | 低 |
| 松木深林 | 高密度松树、低能见度 | 定向、资源搜索 | 迷路 |
| 溪谷 | 河流、湿地、岩石 | 寻路、跨越、取水 | 湿滑、落差 |
| 山脊 | 稀疏植被、远景 | 观察地标、路线规划 | 强风、坠落 |
| 废弃守林站 | 建筑、日志、设备 | 调查、环境谜题 | 黑暗 |
| 雾林 | 浓雾、异常声响 | 主线探索 | 低能见度、未知威胁 |

### 5.2 导航原则

- 远景地标负责大方向：山峰、瞭望塔、巨树、烟柱。
- 中景地标负责路线确认：溪流、岩壁、倒木、废弃路牌。
- 近景线索负责交互：脚印、划痕、遗落物、折断树枝。
- 关键路线至少提供两种可识别线索，避免玩家只能依赖试错。

## 6. 系统设计

### 6.1 体力与状态

第一版只保留轻量状态：

- 体力：冲刺和攀爬消耗，停止后自动恢复。
- 体温：恶劣天气或夜间缓慢下降，可通过营火恢复。
- 受伤：跌落或动物攻击导致，使用急救包恢复。
- 不加入饥饿、口渴等高频管理，避免打断探索节奏。

### 6.2 物品

物品分为四类：

- 工具：手电筒、指南针、相机。
- 消耗品：电池、急救包、引火物。
- 资源：木材、绳索、草药。
- 线索：日志、照片、地图标记、样本。

背包采用有限槽位制。任务关键物品不占普通槽位。

### 6.3 环境谜题

第一版谜题依赖观察和空间关系：

- 根据守林日志找到三个地标。
- 修复木桥或寻找替代渡河路线。
- 调整旧无线电设备恢复信号。
- 根据树木标记判断正确方向。
- 在日落前让山脊反射板对准守林站。

### 6.4 时间与天气

- 昼夜循环以任务节奏驱动，不追求真实时间比例。
- 天气状态包括晴、阴、雨、雾。
- 天气改变能见度、声音传播和部分道路可达性。
- 关键任务可锁定天气，保证叙事和玩法可控。

### 6.5 战斗与威胁

完整版本采用轻量实时战斗，第一人称视角下支持近战、弓箭、闪避和工具技能。敌人以野兽、受异常力量影响的生物和守护者为主。首个垂直切片只实现一种武器和两种敌人。

其他环境威胁包括：

- 野生动物的警告与追逐。
- 落石、陡坡和腐朽木桥。
- 夜间低能见度。
- 浓雾导致的导航困难。
- 突发天气迫使玩家寻找庇护。

## 7. 叙事框架

玩家是一名受委托进入保护区的游侠，任务是调查失联的守林员和异常无线电信号。

叙事通过环境和可选线索展开：

- 废弃营地中的生活痕迹。
- 守林日志和无线电录音。
- 被人为修改的地图标记。
- 不符合季节规律的植被与动物行为。
- 森林深处持续出现的微弱灯光。

第一版结尾：玩家修复山脊信号装置后收到一段来自禁区内部的回应，解锁通往雾林的道路。

## 8. 美术与声音方向

### 8.1 视觉

- 写实但不过度追求影视级资产。
- 冷暖光对比表现安全区与未知区域。
- 使用雾、体积光和植被层次制造深度。
- 保持地标轮廓清晰，不能因写实植被破坏可读性。

### 8.2 声音

- 使用空间音频帮助玩家判断溪流、动物和风向。
- 不同区域拥有独立的环境声层。
- 音乐低频出现，把安静和自然声作为主要氛围。
- 危险接近时先用环境变化提示，而不是直接弹出 UI。

## 9. 首个垂直切片范围

### 9.1 必须完成

- 第一人称控制器。
- 约 1 km × 1 km 的开放区域，用于验证流式加载、探索密度和远景地标。
- 营地、松木林、溪谷和守林站四个区域。
- 拾取、调查、背包和任务系统。
- 体力、手电筒和基础受伤状态。
- 一项包含三个步骤的主任务、两个世界事件和一个隐藏地点。
- 基础近战或弓箭战斗、两类敌人和简单掉落。
- 一种天气变化和昼夜切换。
- 保存与读取。
- Windows 构建和基础设置菜单。

### 9.2 暂不实现

- 多区域组成的完整开放世界。
- 联机与多人玩法。
- 多武器、技能树和复杂敌人生态。
- 复杂动物生态模拟。
- 玩家直接使用自然语言生成地图。
- 云端 AI NPC 对话。
- 随机生成完整剧情。

## 10. 垂直切片验收场景

玩家从营地出发，携带地图、指南针和手电筒进入松木林；通过溪流和山脊地标找到废弃守林站；收集保险丝、燃料和无线电频率记录；修复山脊信号装置并收到神秘回应；随后安全返回营地。

完整流程应在首次游玩 20～30 分钟内完成，同时允许玩家偏离主线发现世界事件和隐藏地点。流程不依赖开发者提示，不出现阻断进度的问题。
