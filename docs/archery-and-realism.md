# 弓箭手感与真实感规格

- 文档版本：V1.0
- 适用阶段：M2 垂直切片收尾 → M3
- 覆盖范围：箭矢供应决策、箭矢留痕、真实感提升清单
- 前置：[`vertical-slice-completion.md`](./vertical-slice-completion.md)（M2 收尾）、[`combat-and-progression.md`](./combat-and-progression.md)（战斗与成长）

---

## 1. 现状审计

以下数字都是实测出来的，不是估计。测法：临时探针脚本跑一遍真实场景，
量完即删（探针不留在仓库里）。

### 1.1 箭矢供应现状

| 项 | 实测值 | 来源 |
|---|---:|---|
| 初始箭矢 | 12 | `main.gd` `STARTING_GEAR` |
| 背包普通槽位 | 12 | `inventory.gd` |
| 箭矢单格堆叠 | 20 | `arrow.tres` `max_stack` |
| 林狼掉落 | `arrow` ×2 | `wolf.tscn` |
| 全场箭矢来源 | 初始 12 + 3 只狼 × 2 = **18 支封顶** | 实测 |
| 射出的箭 | 命中后**钉在表面 6 秒，然后消失** | `arrow_projectile.gd` `stuck_duration` |

**所以箭矢现在不是无限的，是稀缺到影响可玩性的。**

18 支要撑完 20～30 分钟的垂直切片，而异常守护者 240 血、弱点箭 64 伤害，
单是它就要 4 发。玩家打偏几箭就打空了，而打空的唯一来源是杀狼——
而狼杀一只少一只。

### 1.2 真实感缺口清单

| # | 缺口 | 现状 | 影响 |
|---|---|---|---|
| 1 | **箭打出去就没了** | 钉 6 秒自动消失 | 森林里不留任何"我来过"的痕迹。射偏了也看不出来 |
| 2 | **没有任何音频资产** | `game/assets/` 是空的 | 弓箭游戏没有声音，是最大的"假" |
| 3 | **体力约束太软** | 只影响蓄力速度 | 站着连射不累，体力形同虚设 |
| 4 | **命中没有分级** | 敌人 / 树 / 石头 / 地面表现一致 | 箭插在哪、插多深、什么声音都一样 |
| 5 | **满蓄力无疲劳** | 蓄满后可以一直举着 | 没有"瞄准"这个动作的代价 |
| 6 | **过度狩猎无代价** | 箭多就能无脑刷狼 | 森林对玩家的行为没有反应 |

## 2. 决策 A：箭矢无限供应

### 2.1 裁决

**箭矢改为无限供应。玩家不会因为没箭而无法推进。**

### 2.2 理由

1. **稀缺已经在制造挫败，而不是紧张。**
   18 支封顶、唯一的补给是杀狼，而狼是有限资源。
   玩家被迫在"保存弹药"和"探索"之间做选择，但这个选择没有乐趣——只有焦虑。

2. **箭矢在这个游戏里本来就不是一个有意义的资源。**
   它没有配方、没有稀缺变体、没有获取路线。箭矢资源的深度为零，
   却要来承担"打空就卡关"的重量，不划算。

3. **垂直切片的目的是验证手感，不是验证后勤。**
   `development-plan.md` §1 的策略是「先验证可玩性，再扩展世界」。
   弓的**手感**才是这一轮要验证的东西，箭矢计数不是。

### 2.3 影响面

| 项 | 改动 |
|---|---|
| `bow.gd` | 发射不再扣背包；不再发 `ammo_changed` |
| `hud.gd` / `hud.tscn` | 箭矢标签改为显示「箭矢 ∞」 |
| `main.gd` | `STARTING_GEAR` 去掉 12 支箭 |
| `wolf.tscn` | 掉落从 `arrow` ×2 改为 `ration` ×1（箭无限了，箭矢掉落物是垃圾） |
| `EventBus` | 移除 `ammo_changed` 信号（已无发射方与接收方） |
| `arrow.tres` | 物品保留但不再发放（留作将来做制作/回收的接驳点） |
| `combat-and-progression.md` §2 / §8 | 「弹药」从基础资源表降级；「箭矢资源」从垂直切片必做项移除 |

### 2.4 与既有文档的冲突

`combat-and-progression.md` §8「垂直切片范围 · 必须实现」列了
「生命、体力和**箭矢资源**」。本决策与它冲突，**以本决策为准**，
`combat-and-progression.md` §8 已同步改写：箭矢不再是资源，体力成为唯一的消耗型资源。

## 3. 决策 B：箭矢永久留痕

### 3.1 裁决

**射出去的箭留在世界里，不自动消失。**

### 3.2 理由

无限箭之后，如果箭还是 6 秒就没了，那"无限"就只是"凭空变箭"——
世界对玩家毫无反应。真实感恰恰来自**世界留下痕迹**：

- 射偏的箭插在树干上，玩家走过来能看见自己偏了多少；
- 一路走一路射，森林里插着你射过的箭 —— **这是"我来过"最直接的证据**；
- 箭插在狼身上，狼走了箭跟着走，狼死了箭留在原地。

这比任何数值系统都更能制造"这是一个真实的地方"的感觉。

### 3.3 实现约束

| 约束 | 取值 | 理由 |
|---|---:|---|
| 留痕时长 | 永久（直到超出数量上限） | 见 §3.2 |
| 场上同时存在上限 | 40 支 | 插满几千支既不真实也拖垮场景。超出时**最早的那支消失** |
| 命中敌人后 | 箭留在命中点，独立于敌人 | 狼死缩小消失时，箭留在它倒下的地方 |
| 箭的颤动 | 命中后约 0.4 秒的余震，然后静止 | 箭杆插进去时其实还在震 |

箭矢实体挂在玩家父节点（世界空间），不跟玩家走 —— 玩家离开后箭留在原地。

## 4. 真实感优化清单

决策 A、B 解决了"箭无限"和"有痕迹"两件事。下面是**还没做**的部分，
按性价比排序。每项都标了技术落点，可以直接开工。

### P0 —— 让无限箭有代价

无限箭最大的风险是玩家可以站着无脑连射。真实感必须从别处来。

#### P0-1 手臂疲劳

| 表现 | 做法 | 落点 |
|---|---|---|
| 举弓久了准星扩大 | 满蓄力后继续举弓，按时间缓慢扩大准星扩散；松手后恢复 | `bow.gd` 已有 `_charge` / `_aiming`，加 `_fatigue` 计时，叠加到准星扩散量 |
| 蓄力超时脱手 | 满蓄力后超过 N 秒没射，手臂撑不住，弓脱手，需要重新搭箭（约 0.6 s 复位） | 打断"一直瞄着不放"的打法 |
| 连射后手抖 | 短时间内连射 N 箭后准星抖动加剧，需要停顿 | 记一个 `_recent_shots` 计数与时间窗 |

这三项是弓箭游戏里最经典的"真实"来源：**瞄准是有成本的**。

#### P0-2 箭矢落点反馈

命中后除了扣血，还应该告诉玩家"打得好不好"：命中的材质不同，
插入的姿态、深度、声音都不同。

| 命中目标 | 箭的姿态 | 备注 |
|---|---|---|
| 树干 | 垂直于表面钉入 | 需要射线拿到碰撞法线 |
| 地面 | 斜插进去 | 沿入射方向 |
| 岩石 | 弹开掉落 | 硬目标不该插住 |
| 敌人 | 留在命中点 | 随敌人移动则需作为子节点 |
| 已有箭矢 | 替换掉旧的 | 避免叠成一堆 |

### P1 —— 反馈分级与声音

#### P1-1 命中分级反馈

按材质区分音效、粒子与插住姿态。技术前提是有音效资产（见 P1-2）。

#### P1-2 音频资产

**这是目前最大的真实感缺口**：`game/assets/` 是空的，
项目里一个音频文件都没有，`world_audio.gd` 只是个区域音量管理器。

需要产出的最小集合：

| 音效 | 触发 |
|---|---|
| 弓弦张力 | 蓄力时，随蓄力升调 |
| 弦松手 | 发射瞬间 |
| 箭矢破空 | 飞行中，随速度变化音高与音量 |
| 命中：树 / 土 / 石 / 敌人 | 按材质 |
| 狼嚎 / 受击 / 死亡 | 战斗 |
| 脚步 | 按地表材质 |

代码侧需要先留好接口：`ArrowProjectile` 按命中类型发
`EventBus.arrow_impact(material: StringName)`，
由音频层订阅。**接口可以先做，资产后补**。

#### P1-3 环境声与天气联动

雨天应有雨声，溪流附近应有水声。现在 `world_audio.gd` 有区域机制，
但同样没有音频资产。

### P2 —— 森林对玩家有反应

#### P2-1 过度狩猎的代价

无限箭 + 无限体力 = 玩家可以无脑刷狼。森林应该对这种事有反应：

- 射出的箭产生噪声（现在有 1.2 s 的位置暴露），可以扩展成"附近的狼听到几声枪响"；
- 连续击杀超过阈值后，附近刷新更多狼；
- 守林员的记录里出现"这片林子的狼比往常多"。

#### P2-2 弓本身的物理细节

- 松手后弓弦的阻尼摆动（视觉上弦抖两下再停）；
- 满蓄力时弓臂的微小形变（低多边形难做，可以用极小的旋转代替）；
- 箭矢飞行时箭尾的轻微摆动（箭杆的纵向振动）。

#### P2-3 音速延迟

箭速 42 m/s，远低于音速 343 m/s，所以箭比声音先到。
但这个"先到"在远处会变得明显——可以让**箭的破空声延迟到达**，
远处听到声音时箭已经飞过一小段，真实感立刻出来。

## 6. 验收标准

- 玩家在任何时刻都能发射，箭矢数量不再显示具体数字。
- HUD 显示「箭矢 ∞」。
- 射出的箭命中后留在世界里，不会自动消失。
- 箭命中后会短暂颤动，然后静止。
- 场上箭矢超过 40 支时，最早的那支消失。
- 林狼不再掉落箭矢，改为掉落 `ration`。
- 体力仍是唯一的消耗型资源：蓄力消耗体力，体力不足时蓄不满也射不快。
- 冒烟测试全绿。
