# Forest Adventure 文档

《Forest Adventure》是一款以深山森林探索为核心的第一人称开放世界冒险游戏。整体体验参考《原神》的区域探索、地标引导、世界任务和环境解谜，但采用原创世界观、第一人称玩法与写实森林风格。

玩家独自在广阔、陌生且不断变化的森林中探索，通过辨认环境、收集物资、搭建营地、解决自然谜题并逐步揭开森林秘密来推进游戏。AI 与 Blender 用于开发期的程序化场景生产，不作为玩家直接使用的产品。

## 引擎分工

- Godot Engine：游戏本体与开放世界运行时，负责玩家、物理、战斗、任务、AI、分块加载、天气、存档和发布。
- Blender：制作或程序化生成地形、植被、岩石、建筑和动画资产。
- AI 工具：把设计意图转换为受约束的场景配置，辅助 Blender 批量生产内容。

Godot 是必需的；Blender 和 AI 是内容生产工具，不能替代游戏引擎。

## 当前版本目标

开放世界是完整产品目标。开发阶段先完成一个 20～30 分钟的单人垂直切片：

1. 第一人称移动、观察、冲刺和交互。
2. 一张可探索的深林地图。
3. 收集三类资源并完成一个环境任务。
4. 昼夜和基础天气氛围。
5. 一个明确的探索目标与结局触发点。
6. Windows PC 可执行程序。
