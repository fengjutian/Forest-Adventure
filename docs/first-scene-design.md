# 第一个场景设计：暴雨后的林间营地

- 场景 ID：region_00_camp
- 场景类型：安全区 / 新手教学 / 主线起点
- 建议面积：约 120 m × 120 m
- 目标体验时长：5～8 分钟
- 目标引擎：Godot 4.x

## 1. 设计目标

第一个场景使用“暴雨后的林间营地”。它既是安全区，也是教学区域，并通过远处地标自然引导玩家进入开放世界。

玩家应在不依赖开发者说明的情况下学会：

- 第一人称移动、观察、冲刺和跳跃。
- 拾取、调查和使用物品。
- 查看地图、指南针和任务。
- 使用弓箭或基础工具。
- 理解第一个主线目标：前往守林站恢复通信。

教学尽量通过环境和任务完成，避免连续弹窗。输入提示只在玩家第一次遇到对应行为时短暂显示。

## 2. 空间布局

~~~text
                         北 / 山脊信号塔
                              ▲
                              │ 远景地标
                    ┌─────────┴─────────┐
                    │   通往松木深林     │
                    │  倒木形成天然入口  │
                    └─────────┬─────────┘
                              │
                训练靶场 ── 中央营火 ── 物资棚
                    │          │           │
                    │        玩家出生      │
                    │          │           │
                 溪流 ──── 主木屋 ──── 发电机
                              │
                       被落石封闭的返程路
~~~

布局原则：

- 营地内部紧凑，主要交互点之间步行不超过 20～30 秒。
- 外围使用树林、岩壁、溪流和落石形成自然边界。
- 木屋出口正对中央营火，远处能够看见山脊信号塔。
- 松木深林入口必须形成明显的明暗和空间对比。
- 主路线清晰，同时提供一条通往隐藏地点的可选小路。

## 3. 开场设计

使用“声音先出现，画面后出现”的方式开场：

1. 黑屏中先听见雨声、风声和无线电杂音。
2. 画面逐渐亮起，玩家在主木屋内醒来。
3. 桌面上放着地图、指南针和一段守林员留言。
4. 玩家拾取装备后推门离开木屋。
5. 开门瞬间看到远处山脊上的信号塔。

开门画面是首个重要构图：

- 近景：屋檐雨水、木门和营地物品。
- 中景：营火、发电机和训练靶场。
- 远景：森林上方的信号塔。
- 光线：木屋内部偏暖，森林与天空偏冷。

## 4. 教学流程

### 4.1 木屋：观察与拾取

玩家首先拾取：

- 纸质地图。
- 指南针。
- 手电筒。
- 守林员日志。

日志内容保持简短：

> 暴雨损坏了通信设备。守林站一直没有回应。备用保险丝可能还在溪边物资箱里。

完成拾取后生成短目标：检查营地通信设备。

本阶段教授：

- 移动和视角。
- 交互高亮。
- 拾取物品。
- 打开背包或日志。

### 4.2 发电机与无线电：调查教学

玩家走到发电机和无线电旁进行检查。

调查结果：

- 发电机能够启动。
- 无线电通信模块缺少保险丝。
- 备用保险丝位于溪边物资箱。

任务更新为：前往溪边寻找备用保险丝。

本阶段教授：

- 调查场景对象。
- 阅读交互反馈。
- 任务阶段更新。
- 使用地图和指南针。

### 4.3 溪流：移动教学

前往溪流的短路线上布置：

- 一棵倒木，用于教学跳跃或低矮攀越。
- 一段泥泞区域，用于教学冲刺和体力。
- 清晰的溪水声，用于演示声音导航。
- 一个物资箱，内含保险丝、箭矢和急救包。

道路不能造成玩家迷路，但应允许玩家看到一条暂时无法通过的支路，为后续探索留下记忆点。

### 4.4 训练靶场：战斗教学

玩家从溪边返回时经过简易靶场。

教学内容：

1. 装备弓箭。
2. 按住攻击键进行蓄力。
3. 瞄准三个训练目标。
4. 至少命中一个目标即可继续。

完成后从森林深处传来一次野兽吼声，并出现短暂环境变化，但不立即进入正式战斗。它用于建立紧张感和预告后续威胁。

如果垂直切片暂未实现弓箭，可临时改为投掷石块或使用工具破坏木板。

### 4.5 中央营火：安全区与存档

玩家回到中央营火后：

- 自动记录检查点。
- 可以整理背包。
- 显示当前时间和天气。
- 恢复生命与体温。
- 解锁手动保存入口。

营火需要建立明确的安全感，使玩家理解它是探索前的准备地点。

### 4.6 无线电：开启主任务

玩家安装保险丝后，无线电恢复，收到断续的求救信号：

> ……守林站……别走主路……它们在树林里……

随后发生：

- 松木深林入口处的雾逐渐散开。
- 无线电日志记录信号来源的大致方向。
- 地图标记守林站的搜索区域，而不是精确坐标。
- 主任务更新为“调查失联的守林站”。

至此教学结束，玩家正式进入开放世界探索。

## 5. 环境叙事

营地需要表现“这里刚刚发生过事情”，但不直接解释全部真相。

推荐细节：

- 桌上有没喝完的咖啡。
- 一把椅子倒在无线电旁。
- 泥地上有从营地通往森林的脚印。
- 墙上地图的一块区域被红笔圈出。
- 物资棚门锁损坏，但没有明显盗窃痕迹。
- 守林员床铺没有整理。
- 溪边存在不属于普通动物的爪痕。
- 无线电旁留有半张被雨水浸湿的频率记录。

环境线索分为三层：

- 必看线索：保险丝缺失、守林站失联。
- 易发现线索：脚印、倒下的椅子、损坏的门锁。
- 隐藏线索：异常爪痕、频率记录和地图标记。

隐藏线索可以解锁额外日志，但不能阻断主线。

## 6. 开放世界引导

营地出口不放置巨大的任务箭头。使用世界内信息引导：

- 远处可以看见信号塔。
- 守林站方向传来微弱无线电噪声。
- 倒木、道路和光线共同构成森林入口。
- 路牌标注“Ranger Station 1.8 km”。
- 地图只显示搜索范围，不显示精确目标点。
- 进入正确方向时，植被密度和道路痕迹保持可读。

玩家离开营地时同时看到：

- 主路线：通往松木深林和守林站。
- 可选小路：通往隐藏猎人营地。

隐藏猎人营地提供少量箭矢、环境线索和一个观景位置，让玩家尽早理解“偏离主路会有发现”。

## 8. 场景状态

需要持久化：

- 已拾取的装备。
- 发电机与无线电状态。
- 物资箱开启状态。
- 训练是否完成。
- 已阅读的日志。
- 已触发的无线电内容。
- 森林入口是否开放。
- 隐藏营地是否发现。
- 当前任务阶段。

任务阶段建议：

~~~text
intro_started
→ collect_equipment
→ inspect_radio
→ find_fuse
→ return_to_camp
→ repair_radio
→ investigate_ranger_station
~~~

场景对象必须使用稳定 ID，不能以运行时实例 ID 保存状态。

## 9. 美术与音频要求

### 9.1 美术

- 暴雨已经减弱，但地面仍潮湿。
- 营地使用暖色灯光，外围森林使用冷色环境光。
- 木屋和发电机应有清晰轮廓，避免被植被遮挡。
- 信号塔作为远景地标必须在开门构图中可见。
- 主路线周围植被密度较低，非主要方向更密集。
- 教学物品使用自然的构图和光照强调，不统一添加强烈描边。

### 9.2 音频

- 木屋内：雨打屋顶、无线电杂音、木材声。
- 营地：风、滴水、营火、发电机。
- 溪边：随距离变化的水流声。
- 森林入口：更少的人造声音、更强的树木和动物声。
- 修好无线电后：求救信号必须清晰可辨，同时保留失真感。

空间音频既提供氛围，也承担方向引导功能。

## 10. 生产方式

第一个场景以人工设计为主：

- Blender 或森林生成器负责地形、外围树木、岩石和远景。
- 木屋、发电机、物资棚等资产在 Blender 制作。
- 教学路线、任务道具、触发器、音频区和构图在 Godot 中人工布置。
- GeneratedEnvironment 与 AuthoredLandmarks 分层，重新生成自然环境时不能覆盖人工内容。
- 先使用灰盒完成流程测试，再替换正式资产。

## 11. 实施顺序

1. 使用简单几何体搭建营地灰盒。
2. 放置玩家出生点和自然边界。
3. 完成装备拾取、发电机调查和保险丝任务。
4. 加入营火存档点。
5. 完成无线电修复和森林入口开放。
6. 加入靶场与基础武器教学。
7. 邀请首次玩家测试导航和任务理解。
8. 调整路线、构图、距离与提示。
9. 接入正式模型、植被、灯光和音频。
10. 最后进行性能优化与存档回归测试。

## 12. 验收标准

首次接触游戏的玩家应当：

- 在 30 秒内理解如何离开木屋。
- 在 2 分钟内获得地图、指南针和手电筒。
- 在没有开发者说明的情况下找到发电机和溪边物资箱。
- 理解溪水声、道路和地标可以帮助导航。
- 完成至少一次武器操作。
- 在 8 分钟内修好无线电。
- 清楚知道下一步应进入森林调查守林站。
- 能发现主路线之外至少一个可选线索。

技术验收：

- 任务在存档、退出和重新加载后保持正确状态。
- 已拾取物品不会重复生成。
- 玩家不能通过场景边界或教学触发器进入异常状态。
- 场景在目标硬件上达到既定帧率。
- 从营地进入松木深林时不出现明显加载停顿。
